Дата: 22 октября 2026. Основание: [STANDARDS.md](STANDARDS.md).
Проверены GUI/диспетчеризация, профиль, IPC клиента/службы, маршруты/откат,
установщик, сборка и публикационные ограничения. Это self-review с регрессиями,
не независимый аудит и не заявление об отсутствии всех уязвимостей.

Приоритеты показывают риски проекта, а не номера CVE/оценку эксплуатации.
R05 уменьшает риск гонок при чтении; он не доказывает подлинность исходного
пакета без Developer ID. Администратор всё ещё должен доверять скачанной сборке.

Финальная проверка встроенным Python выявила разницу C-декодеров Python 3.9/3.12:
одного перехвата RecursionError недостаточно для одинаковой границы вложенности.
Добавлен собственный лимит JSON 64 уровня до декодирования, с учётом строк и
экранирования. Регрессия остаётся строгой и проходит на обоих runtime.

## Подтверждены существующие защитные решения

- UID проверяется с обеих сторон локального канала; сокет ограничен нужным
  пользователем. Нет общедоступного TCP-порта и API произвольных shell-команд.
- Ввод и MFA остаются в FortiClient/окне macOS. Нет своего поля пароля, Keychain
  чтения, сохранённых credentials, NOPASSWD или запуска всего GUI от root.
- TLS контрольных запросов не отключается. DNS/IPv6 не переписываются.
- Контроль собственных маршрутов и откат не расширяются на чужие записи;
  broad private routes не добавляются, повторяющаяся борьба с VPN не ведётся.
- `emit` уже обрабатывал разрыв stdout: это проверено новой регрессией, а не
  объявлено новым исправлением. Потеря телеметрии не должна мешать откату.
- Установка готовит копию до остановки службы; ошибка bootstrap возвращает
  предыдущую версию, неизвестные файлы не удаляются рекурсивно.

## Что не закрыто автоматически

1. Developer ID/notarization и запуск под корпоративной политикой: нет сертификата,
   нельзя решить локальной имитацией подписи. Нужен подписанный распространяемый выпуск.
2. Продолжительный сквозной VPN-тест новой GUI-сборки, звонок/RDP, реальные
   сон/обрыв/другая сеть и первый admin install на втором Intel Mac — ручная приёмка.
3. Полный Windows-порт, Apple Silicon и исчерпывающая матрица macOS/Forti/EMS —
   не реализованы, не маскируются заглушкой "успех".
4. Нет per-app isolation, split DNS/IPv6 или fail-closed. Это ограничения выбранной
   архитектуры, а не исправления оформления.
5. Аппаратный сбой/повреждение root-журнала, отсутствие помощника при незавершённом
   откате и нестандартный длинный TMPDIR могут потребовать администратора.
6. VoiceOver, увеличение контраста, разные локализации и внешний аудит требуют
   отдельной ручной проверки. Авто-проверка label/appearance не заменяет её.
7. Авторизация локальной службы делегирована UID, а не удостоверенной подписи GUI.
   Узкий API не является защитой от всех враждебных процессов того же пользователя;
   для усиления identity потребуется отдельно спроектированный подписанный IPC.

До закрытия ручной приёмки версия остаётся **preview**, не "универсально проверенной".
