# Forti Split — Intel Mac и Windows Companion

Небольшое macOS-приложение для одновременной работы FortiClient VPN и обычного
интернета. Рабочие IPv4-адреса остаются в VPN, остальной IPv4-трафик направляется
через физический сетевой шлюз. Это разделение **по адресам, не по приложениям**.

Для Windows есть отдельный ограниченный
[Companion 0.1.1 Preview](https://github.com/RelakRE/catalazhka_dlya_forti/releases/tag/windows-v0.1.1):
FortiClient/MFA → проверка рабочего пути → RDP/TrueConf, настройки и трей.
**Он не меняет маршруты и не устраняет потерю интернета при full-tunnel VPN.**
[Инструкция и границы Windows](windows/README.md), [Windows review](windows/REVIEW.md).
Далее на этой странице описана Intel-версия.

## Скачать и запустить

[Скачать Forti Split 1.4.1 — Intel Preview](https://github.com/RelakRE/catalazhka_dlya_forti/releases/tag/v1.4.1).
Выберите `Forti-Split-1.4.1-Intel.zip`, а не архив исходников GitHub.
Предыдущие версии остаются доступны в разделе Releases.

- Только Intel (`x86_64`), заявленный минимум macOS 13. Реально проверяется на
  macOS 14 Intel; другие версии и чужие VPN-политики требуют отдельного теста.
- Python уже включён. Для запуска не нужны Xcode, Homebrew и отдельный Python.
- Нативный FortiClient должен быть установлен отдельно. Вход, пароль и MFA
  выполняются только в нём. VPN внутри виртуальной машины нужно отключить.
- Рабочие адреса в публичную сборку **не включены**. Получите приватный JSON-профиль
  по внутреннему каналу и выберите его на первом шаге мастера.
- На втором шаге разрешите установку системного помощника в окне macOS. Он меняет
  маршруты от root; для установки нужны права администратора. Пароль не сохраняется.
- В мастере выберите, открывать ли RDP-файл и TrueConf после подключения.
  Оба запуска отключены по умолчанию; их можно изменить в настройках.
- После настройки нажмите «Начать работу». Приложение проверит/подготовит сеть,
  откроет FortiClient и дождётся входа с MFA. После успешного VPN оно само включит
  разделение и только после проверок откроет выбранные приложения.
- Для завершения нажмите «Завершить работу», дождитесь отката и отключите VPN
  в открывшемся FortiClient. RDP и TrueConf принудительно не закрываются.
- При отключении VPN через FortiClient или обрыве связи приложение дождётся
  отката и предложит «Начать работу» снова. Автоматического переподключения нет.
  Неподтверждённый откат по-прежнему требует восстановления, а не нового сеанса.
- Ошибки показываются кратко; технические сведения доступны в журнале настроек.
  После установки помощника ожидается запуск службы. Если проверка не прошла,
  повторите проверку доступа без повторного ввода системного пароля.

Интерфейс следует светлой/тёмной теме macOS. На вкладке «Работа» — статус и одна
основная кнопка. Все настройки и обслуживание находятся на вкладке «Настройки».
Закрытие окна скрывает его; приложение продолжает работать через значок строки
меню. Настоящий выход ждёт отката. Опциональный запуск при входе в macOS открывает
только интерфейс, не VPN. FortiClient можно автоматически скрывать без отключения.

## Важное предупреждение

Версия 1.4.0 — **предварительный тестовый выпуск**, не готовый универсальный
корпоративный продукт. Базовый механизм маршрутов подтверждён в одной конфигурации;
новая автономная GUI-сборка требует сквозной приёмки с реальным VPN.

Сборка имеет только ad-hoc подпись, **без Developer ID и нотариального заверения
Apple**. Проверка целостности подписи не подтверждает личность издателя.
macOS может заблокировать скачанный файл. Не отключайте Gatekeeper/SIP и не
снимайте защиту командами из случайных инструкций. Если политика Mac разрешает,
используйте штатное подтверждение запуска в настройках безопасности; если
разрешение недоступно, остановитесь и обратитесь к администратору.
[Официальная справка Apple](https://support.apple.com/102445).

Согласуйте использование с правилами своей организации. Приложение не меняет
FortiGate/EMS, не отключает компоненты защиты FortiClient и не обходит MFA.
Не гарантируется работа с любой корпоративной политикой VPN.

## Что приложение не делает

- Не реализует per-app VPN, split DNS или прямой IPv6: DNS/IPv6 остаются как у FortiClient.
- Не обеспечивает fail-closed рабочих приложений при падении VPN.
- Не обнаруживает автоматически все зависимости рабочих сервисов.
- Не включает маршруты автоматически после перезагрузки и не входит в VPN.
- Не отправляет профили/диагностику разработчику и не проверяет обновления в фоне.

Проверки доступности выполняют HTTPS HEAD к `example.com` и `www.apple.com`.
Приватные отчёты содержат сетевые адреса: **не прикладывайте их к публичным Issues**.

Сторонние компоненты и их лицензии: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
FortiClient, Windows App и TrueConf не входят в поставку.
