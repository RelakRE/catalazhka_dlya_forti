# Использование

1. Скачайте ZIP из Releases, распакуйте и перенесите приложение `Forti Split Intel`
   в удобную постоянную папку, например «Программы». Не запускайте прямо из архива.
2. Прочитайте предупреждение о тестовой неподтверждённой Apple сборке в README.
3. На шаге «Профиль» нажмите «Выбрать файл профиля…». Выберите приватный
   профиль JSON, полученный по внутреннему каналу. Для другого окружения нужен
   свой список серверов и DNS. Проверки блокируют пустые и некорректные профили.
4. На шаге «Доступ» нажмите «Разрешить системный доступ…» и подтвердите системный запрос администратора.
   Приложение проверит root-помощник без изменения сети. При обновлении установленной
   версии помощника снова понадобится разрешение. Уже актуальному помощнику
   нужна только проверка без нового пароля. Постоянный ввод пароля при
   включении/отключении после успешной установки не нужен.
5. На этапе «Рабочее место» выберите отключаемые опции: запуск RDP, TrueConf,
   скрытие FortiClient. Автозапуски программ по умолчанию выключены. Если нужен
   RDP, выберите доверенный `.rdp`-файл; для него нужна отдельно установленная
   Windows App. Убедитесь, что адреса рабочего стола и RD Gateway есть в профиле.
6. Отключите VPN и нажмите «Начать работу». Приложение проверит доступ и сеть;
   актуальная подготовка используется повторно. Она действует сутки и привязана
   к профилю и физической сети. Если VPN уже подключён, но подготовка недействительна,
   мастер попросит сначала отключить его — маршруты вслепую не применяются.
7. В открывшемся FortiClient подключитесь с обычной MFA. После успешного VPN
   разделение включится и проверится автоматически; только затем откроются
   выбранные программы. Для каждого нажатия они запускаются один раз. Отмена,
   ошибка и обрыв снимают автоматический сценарий. Вход в VPN сам не повторяется.
8. Окно можно закрыть: Forti Split остаётся в строке меню. Цвет значка дополнен
   текстовым статусом: ожидание/подключение/готово/ошибка. Откройте окно из значка
   или Dock. Для завершения нажмите «Завершить работу», дождитесь отката и отключите
   VPN в FortiClient. Пока полный VPN подключён, обычный интернет может не работать.
   Открытые RDP/TrueConf не закрываются: сначала сохраните свою работу.

Не меняйте профиль во время разделения. После импорта нового профиля или смены
Wi-Fi нужна новая подготовка без VPN. Профиль не содержит паролей и не заменяет
конфигурацию FortiClient.

На вкладке «Работа» только информационный блок и одна основная кнопка.
На вкладке «Настройки» можно изменить RDP-файл и выключить любой автозапуск,
скрытие FortiClient, открыть отчёты, сменить профиль или восстановить маршруты.
Настройки блокируются на время активного сценария/сеанса. Forti скрывается
штатным AppKit hide, не отключается и не закрывается; дополнительных разрешений
Accessibility или Automation не требуется. Некоторые версии клиента могут снова
показать своё окно; отказ скрытия не отключает работающее разделение.

«Открывать Forti Split при входе в macOS» — отдельная opt-in настройка. Сначала
перенесите пакет в постоянную папку «Программы». Разрешение контролирует macOS;
если нужно, подтвердите его в «Основные → Объекты входа». При входе запускается
только интерфейс, не VPN и не маршруты. При ошибке регистрации причина видна
в настройках. Это не способ обойти корпоративный запрет.

## Где находятся данные

В домашней папке текущего пользователя:
`Library/Application Support/Forti Split/` — профиль, подготовка и `diagnostics/`.
Данные не хранятся внутри `.app`; перемещение/обновление пакета их не удаляет.
`workplace-settings.json` содержит только выбор опций и локальный путь RDP,
не пароль/OTP/содержимое RDP. Права каталога 700, настроек 600. Он не экспортируется
с рабочим сетевым профилем и не публикуется.
Кнопки «Отчёты» и «Журнал» помогают сохранить результат при разрыве интернета.
Отчёты приватны, публиковать их без отдельной очистки нельзя.

У старой Terminal-версии данные могут находиться в каталоге проекта. Новый
публичный пакет их не читает и не переносит автоматически.

## Системный помощник

Отдельная root-служба launchd устанавливается явно для UID текущего пользователя:

- `/Library/PrivilegedHelperTools/local.fortisplit.helper/<UID>/` — защищённые
  модули и собственная копия Python; не зависят от наличия приложения в «Загрузках».
- `/Library/LaunchDaemons/local.fortisplit.helper.<UID>.plist` — регистрация службы.
- `/var/run/forti-split-helper-<UID>/service.sock` — локальный Unix-сокет с проверкой UID.
- `/var/run/forti-route-probe.lock` — закрытый журнал и блокировка маршрутных изменений.

Служба принимает только status/health/lease/recover с проверкой параметров,
не принимает произвольные команды/пути и не открывает сетевой TCP/UDP-порт.
Код запускается из root-owned каталога в изолированном Python. Нет сохранённых
паролей, sudoers NOPASSWD, setuid-скриптов или GUI от root.

При обновлении новая копия сначала целиком записывается и проверяется; затем
переключается служба. Если регистрация не удалась, выполняется попытка возврата
предыдущей версии. При неуспешном откате/неизвестных файлах диагностическая копия
остаётся в защищённом каталоге; не удаляйте её вручную, сохраните сообщение ошибки.

## Завершение, восстановление и удаление

Закрытие окна только скрывает его. Выход через меню/Command-Q ждёт отката;
при коде неподтверждённого отката окно остаётся для восстановления. При сбое
процесса GUI/бэкенда потеря локального канала
запускает независимый откат. Обрыв VPN, смена сети/DNS, пропажа собственного
маршрута и длительный сон также завершают сеанс. Принудительное убийство самого
root-помощника, сбой ОС или ошибка системной команды могут помешать откату.

Если откат не подтверждён, нажмите «Восстановить», проверьте отчёт и не удаляйте
журнал вручную. При необходимости штатно отключите FortiClient.
Если помощник пропал при незавершённом журнале, новый сеанс блокируется: нужен
прежний инструмент восстановления/администратор, а не новая установка поверх
неизвестных изменений. Мастер объясняет это состояние отдельно.

Для удаления службы: сначала остановите разделение, затем меню
Forti Split → «Удалить системный помощник…». Требуется разрешение администратора.
Удаляются только известные файлы нашей службы и runtime; неизвестные файлы
не удаляются рекурсивно. Приложение, профиль, отчёты и FortiClient сохраняются.
Пустые родительские/сокетные каталоги и неактивный журнал могут остаться.
