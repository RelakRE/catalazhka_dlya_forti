# Forti Split 1.2.0 — Intel preview

Предварительный автономный выпуск для Intel (`x86_64`). Python уже внутри.
Рабочие адреса и профили в поставку не входят.

## Установка

1. Скачайте `Forti-Split-1.2.0-Intel.zip` и распакуйте приложение.
2. Прочитайте README, особенно предупреждение о подписи и корпоративной политике.
3. Получите приватный JSON-профиль по внутреннему каналу и импортируйте кнопкой.
4. Явно установите помощник через системное окно macOS. При переходе со старой
   локальной версии потребуется однократное обновление помощника с разрешением
   администратора; активный сеанс сначала нужно завершить.
5. Подготовьте без VPN, подключите FortiClient/MFA, включите разделение.

Полная инструкция и ограничения находятся в README/USAGE репозитория.
`SHA256SUMS.txt` содержит контрольную сумму архива.

## Изменения

- Нативное окно с включением/отключением, восстановлением и локальными отчётами.
- Нет ограничения в 30 минут, но сохранены защиты состояния сети и откат.
- Импорт приватного профиля с проверкой, атомарным сохранением и правами 600.
- Отдельная root-owned служба со встроенным проверяемым Python; пароль не хранится.
- Транзакционное переключение установленного помощника с попыткой восстановления
  предыдущей версии при ошибке регистрации.
- Публичная история начинается с очищенного root-коммита, без приватных предков.

## Что проверено

На Intel macOS 14: 103 автоматических теста проходят как на исходном Python,
так и на встроенном CPython 3.12.15; 11 UI-состояний проходят; установочный
комплект помощника проверен по хешам; подпись пакета проходит проверку целостности.
Тестовые адреса синтетические, реальные маршруты тесты не изменяют.

Базовый механизм маршрутизации ранее работал в одном реальном окружении.
**Сквозная приёмка именно этой автономной GUI-сборки с настоящим VPN ещё не подтверждена.**
На другом Mac, другой macOS и с другой политикой VPN нужны отдельные испытания.

## Подпись и ограничения

**Ad-hoc подпись, без Developer ID и нотариального заверения Apple.**
macOS/корпоративная политика может запретить запуск. Не отключайте Gatekeeper/SIP.
Это тестовый выпуск, не универсальный корпоративный установщик.

Только IPv4-разделение по адресам, не изоляция отдельных приложений.
DNS/IPv6 без изменений, нет fail-closed при падении VPN. Не прикладывайте
приватные профили и сырые отчёты к публичным Issues.
