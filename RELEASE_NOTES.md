# Forti Split 1.3.0 — Intel Preview

Предварительный Intel-выпуск 1.3.0. Релиз 1.2.0 остаётся доступен для возврата.
Сквозная приёмка новой GUI-сборки с настоящим VPN ещё не подтверждена.

## Изменения

- Системная светлая/тёмная тема, включая изменение оформления без перезапуска.
- Пошаговый мастер: профиль → системный доступ → сеть → VPN. Одно основное действие;
  нет лишнего подтверждения перед настоящим системным запросом пароля.
- Читаемый адаптивный интерфейс, прокрутка и отдельная скрытая группа обслуживания.
- Переносимые модель профиля, JSON и сценарий мастера; поздний выбор OS-адаптера.
  Windows пока отвечает явным отказом, а не выполняет команды macOS.
- Health привязан к версии установленного помощника. Подготовка/включение требуют
  успешной проверки; отсутствие FortiClient/другой VPN/проблемы восстановления видны.
- Ограничения времени IPC/status, строгий JSON, чтение install payload через
  дескрипторы, сохранение busy до окончания живого отката, закрытые пользовательские
  каталоги и атомарное сохранение.
- Проверка источников сборки и привязка UI-доказательств к конкретному executable.
- Применимые практики, внутреннее ревью и матрица переносимости:
  STANDARDS.md, REVIEW.md, PORTABILITY.md.

## Переход с предыдущей версии

1. Штатно завершите активное разделение и дождитесь отката.
2. Откройте новый отдельный Intel-пакет. Существующий пользовательский профиль
   сохраняется, повторный импорт обычно не нужен.
3. На этапе доступа обновите помощник через системное разрешение macOS.
   Новая версия его модулей требует однократного подтверждения администратора.
4. Дождитесь health, подготовьте сеть без VPN, подключите FortiClient с MFA
   и включите разделение. Во время первого реального теста держите отчёты доступными.

## Проверки и ограничения

Результаты автоматических, UI и архивных проверок сохраняются в VALIDATION.json.
Работа нового пакета с настоящим VPN, звонком/RDP, сном и другим Intel Mac
ещё требует ручной приёмки. Проверки не выполняют настоящие маршрутные изменения.

По-прежнему только Intel; готового Windows/Apple Silicon-порта нет.
DNS/IPv6 не разделяются, per-app isolation и fail-closed не реализованы.

Ad-hoc подпись — без Developer ID и нотариального заверения Apple. macOS может
запретить скачанный пакет. Не отключайте Gatekeeper/SIP; нужна разрешённая штатная
процедура или подписанная поставка. Профили/сырые отчёты не публикуются.
