# Forti Split 1.2.1 — Windows x64 Preview

Исправлена блокировка RDP через шлюз, если VPN DNS не знает имя целевого
компьютера. Для режима шлюза проверяется сам шлюз; в режиме автоматического
выбора прямой маршрут добавляется, если имя компьютера удалось разрешить.
При прямом RDP разрешение целевого имени по-прежнему обязательно.
Цель и содержимое выбранного RDP-файла не изменяются.

Скачайте **Forti-Split-1.2.1-Windows-x64.zip**, распакуйте весь архив и откройте
**Forti Split.exe**. Отдельно устанавливать .NET не требуется.

При первом запуске нужен интернет: окно подготовки автоматически загрузит
OpenConnect 9.21, Wintun 0.14.1 и временный архиватор из официальных источников.
Все исполняемые загрузки проверяются по зафиксированному SHA256 перед запуском
или распаковкой. Временный архиватор удаляется. VPN при подготовке не подключается.
Папка приложения должна быть доступна для записи.

- Вход, пароль и 2FA — в интерфейсе приложения.
- Сохранение пароля по галочке — через Windows Credential Manager.
- Рабочие маршруты и DNS, обычный интернет через исходное подключение.
- Запуск RDP и TrueConf, настройки, трей и восстановление сети.
- Приватный профиль импортируется в настройках; реальных рабочих адресов в архиве нет.

Перед подключением отключите FortiClient. При подключении разрешите сетевой
компонент в запросе Windows. Для завершения нажмите «Отключить».

Проверки: конфигурация и авторизация, моделирование восстановления сети,
подготовка официальных зависимостей, нативная библиотека, хранилище паролей и IPC.
Подробности — в `WINDOWS-VALIDATION.json`; контрольные суммы — в `SHA256SUMS.txt`.

**Предварительный выпуск без подписи издателя.** Реальный вход в VPN через новую
GUI-форму, вход в RDP и звонок TrueConf не подтверждены автономными проверками.
Если политика Windows запрещает запуск, обратитесь к администратору.
Не публикуйте приватные профили и журналы в Issues.
