# Forti Split 1.2.5 — Windows x64 Preview

Исправлено неограниченное ожидание ответа сервера при входе в VPN.
Сетевое ожидание ограничено 90 секундами; время, пока пользователь вводит пароль
или код 2FA в форме приложения, в этот срок не входит. После отправки формы
отсчёт начинается заново. Тайм-аут не выдаётся за ошибку пароля.

Интерфейс показывает этап входа. Приватный `auth-stage.json` содержит только
название последнего этапа, его номер и время UTC. Содержимое форм, пароль,
одноразовый код и cookie в этот файл не записываются. Проверка TLS сохранена.
Настройки и сохранённые учётные данные версии 1.2.4 совместимы с этим выпуском.

Сохранены исправления начальной настройки маршрутов и DNS из версии 1.2.4:

Исправлена неполная начальная настройка доступа к RDP из продолжения issue #1.
Теперь заранее заданные IP шлюза и DNS-правила рабочих доменов применяются до
первого DNS-запроса, как в WorkVPN. Отрицательный DNS-кэш очищается при настройке.
Это не зависит от имени выбранного рабочего ПК и не требует фоновой диагностики.

**Нужен обновлённый приватный профиль:** адреса шлюза в `ExtraHosts`, рабочие
DNS-домены в `DnsDomains`. Получите его у владельца проекта по приватному каналу,
импортируйте в настройках и укажите свой логин и локальный RDP-файл. Эти сетевые
данные не включены в публичный архив. Одна замена EXE со старым неполным профилем
не добавит отсутствующие адреса и домены.

Статус интерфейса уточнён: «VPN-сеанс активен» не является проверкой доступности RDP.

Исправление [issue #1](https://github.com/RelakRE/catalazhka_dlya_forti/issues/1):
убраны повторное применение DNS каждые две минуты и проверка пересечения DNS-политик,
из-за которых программа могла сама отключить исправно работающий VPN.

Удалены интернет-проверка, служебные отчёты самодиагностики и процесс-сторож.
Во время работы программа не тестирует сеть и не меняет её настройки по таймеру.
Рабочая сеть настраивается один раз при подключении и при реальном переподключении
OpenConnect. Обычное «Отключить» или выход выполняют штатную очистку.
После аварии или неожиданного разрыва нажмите **«Восстановить сеть»**:
кнопка завершит оставшийся процесс этого сеанса и снимет его сетевые настройки.

Убрана предварительная проверка RDP: ни имя ПК, ни имя шлюза, ни пробное
TCP-подключение не блокируют VPN. Можно выбирать разные RDP-файлы и короткие
имена компьютеров; файл передаётся клиенту Windows без изменения адреса.
Ошибка DNS рабочего имени не отключает VPN. При подключении маршруты
добавляются для успешно разрешённых адресов. Фактическую доступность рабочего ПК
проверяет mstsc; фоновых проверок доступности приложение не выполняет.

Скачайте **Forti-Split-1.2.5-Windows-x64.zip**, распакуйте весь архив и откройте
**Forti Split.exe**. Отдельно устанавливать .NET не требуется.

При первом запуске нужен интернет: окно подготовки автоматически загрузит
OpenConnect 9.21, Wintun 0.14.1 и временный архиватор из официальных источников.
Все исполняемые загрузки проверяются по зафиксированному SHA256 перед запуском
или распаковкой. Временный архиватор удаляется. VPN при подготовке не подключается.
Папка приложения должна быть доступна для записи.

- Вход, пароль и 2FA — в интерфейсе приложения.
- Сохранение пароля по галочке — через Windows Credential Manager.
- Рабочие маршруты и DNS, обычный интернет через исходное подключение.
- Запуск RDP и TrueConf, настройки, трей и восстановление сети.
- Приватный профиль импортируется в настройках; реальных рабочих адресов в архиве нет.

Перед подключением отключите FortiClient. При подключении разрешите сетевой
компонент в запросе Windows. Для завершения нажмите «Отключить».

Проверки: конфигурация и авторизация, моделирование восстановления сети,
подготовка официальных зависимостей, нативная библиотека, хранилище паролей и IPC.
Подробности — в `WINDOWS-VALIDATION.json`; контрольные суммы — в `SHA256SUMS.txt`.

**Предварительный выпуск без подписи издателя.** Реальный вход в VPN через новую
GUI-форму, вход в RDP и звонок TrueConf не подтверждены автономными проверками.
Если политика Windows запрещает запуск, обратитесь к администратору.
Не публикуйте приватные профили и журналы в Issues.
